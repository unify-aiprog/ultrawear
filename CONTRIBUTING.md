# Contributing to UltraWear FC

## Branches

- `main`: stable integration branch.
- `foundation/*`: foundational work.
- `feature/*`: new product capabilities.
- `fix/*`: bug fixes.
- `chore/*`: maintenance and tooling.

## Pull requests

- Keep each PR focused on one logical outcome.
- Explain the problem, approach, and validation performed.
- Avoid committing secrets or environment-specific configuration.
- Prefer small, reviewable commits.

## Commit style

Use concise conventional-style messages such as:

- `feat: add product catalog`
- `fix: handle empty cart`
- `docs: clarify launch process`
- `chore: update tooling`

## Definition of done

A change is ready when it is documented where appropriate, validated, and understandable to the next contributor.
