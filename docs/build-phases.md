# UltraWear Build Phases

The platform is built in reviewable phases. Each phase must leave the product usable before the next phase starts.

## Phase 0 — Foundation
- Brand/site shell
- FC = For Community
- Sports/lifestyle positioning beyond football
- Accessibility, responsive behavior, navigation
- Content Core contracts and editorial state machine

**Exit:** stable public shell + documented core contracts.

## Phase 1 — Intelligence Brain
- Signal intake and normalization
- Transparent signal scoring
- Deduplication and clustering
- Story opportunity generation
- Research-pack and fact-firewall primitives
- Editorial queue foundations

**Exit:** verified signals can become ranked story opportunities without publishing automatically.

## Phase 2 — Content Production Core
- Canonical story records
- Research workflows
- AI-assisted drafting from verified evidence
- Claim/evidence traceability
- Human editorial gate
- Corrections and revision history

**Exit:** an editor can take an opportunity from research to approved content safely.

## Phase 3 — Publishing + Discovery
- CMS/publishing adapter
- Permanent entity/topic pages
- Sports, team, athlete and event hubs
- SEO/AEO/GEO metadata
- Sitemaps, structured data and internal linking
- Search/Discover-friendly article templates

**Exit:** approved content can publish to the UltraWear domain with durable URLs.

## Phase 4 — Live Sports + Community
- Live scores/events adapters
- Match/event pages
- Follow and alerts foundations
- Reactions, questions, polls and predictions
- Location layers: Near You / Africa / Global / For You

**Exit:** users have reasons to stay, participate and return.

## Phase 5 — Distribution + Owned Audience
- Newsletter/daily brief
- Push/notification candidates
- Social and audio derivatives
- Personal sports graph
- Follow topics, teams, athletes and events

**Exit:** UltraWear can turn anonymous traffic into a returning owned audience.

## Phase 6 — Monetization
- AdSense/programmatic-ready placements
- ads.txt/consent/privacy foundations
- RPM and revenue attribution
- Direct sponsorship inventory
- Affiliate/contextual commerce
- Premium/data product foundations

**Exit:** monetization is measurable without compromising editorial trust or UX.

## Phase 7 — Domain Launch + Hardening
- Main-domain migration from temporary subdomain
- Production hosting/CDN
- Analytics and observability
- Core Web Vitals/performance pass
- Security, backups and recovery
- Redirect/canonical validation
- SEO indexing validation
- Launch checklist and rollback plan

**Exit:** production-ready UltraWear platform attached to the main domain.

## Release rule
No phase is considered complete because code exists. It is complete only when its acceptance criteria are tested and the next phase can consume stable contracts.
