# Live Sports Visual Identity

This layer keeps sports presentation separate from canonical sports data.

## Identity

- Team colours are resolved from `identity.js`.
- Team crest URLs are resolved from `logo-assets.js`.
- Production should replace remote logo endpoints with UltraWear-hosted, rights-cleared or licensed assets.

## Motion

- low: calm ambient movement
- medium: stronger depth and momentum sweep
- high: reserved for genuinely live/high-attention states
- reduced motion: non-essential animation is disabled

The live feed remains truth-first: demo data is explicitly labelled and cannot be mistaken for verified match information.
